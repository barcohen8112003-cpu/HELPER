# HELPER למחשב (Windows)

‏HELPER על המחשב: מחזיקים מקש ומדברים בעברית, והוא פותח אפליקציות, מסדר חלונות בין המסכים, מקליד בכל שדה, קורא את המסך ומצביע איפה ללחוץ. זה אותו HELPER כמו בוואטסאפ ובטלוויזיה.

## המקשים

| מה | איך |
|---|---|
| לדבר | להחזיק **Ctrl+Alt+Space**, לדבר, לעזוב |
| להקליד | **לחיצה קצרה** על Ctrl+Alt+Space, ואז Enter (‏Esc סוגר) |
| הכתבה לכל שדה | להחזיק **Ctrl ימני**, לדבר, לעזוב. הטקסט נכתב בשדה שבו הסמן |
| להצביע על משהו במסך | **Ctrl+Alt+P**, ללחוץ על משהו או לגרור מסביבו, ואז לשאול |
| לבטל | **Esc** |

‏ליד השעון יש אייקון סגול עם H. בתפריט שלו בוחרים בין מודל מהיר לחכם, מדליקים תשובות בקול של HELPER, ומפעילים או מכבים הפעלה עם Windows.

## מה אפשר להגיד

**פקודות מיידיות (בלי AI, פחות משנייה):**
- "תפתח את ספוטיפיי", "תפתח את המחשבון ותשים אותו בצד שמאל"
- "תשים את כרום בצד ימין של המסך השני", "כרום משמאל ודיסקורד מימין"
- "תגדיל את זה", "תמזער את דיסקורד", "תמזער הכל", "תסגור את טלגרם"
- "תגביר", "תנמיך קצת", "ווליום 30", "השתק", "השיר הבא", "תעצור"
- "תחפש מתכון לשקשוקה", "חפש ביוטיוב לופי", "תחפש במפות פיצה בחיפה"
- "מה השעה", "תנעל את המחשב"

**ללמד אותו:**
- "כשאני אומר מצב עבודה, תפתח את כרום ואת ספוטיפיי". מאז, "מצב עבודה" רץ מיד.
- משימה ש-Claude פתר פעם, נשמרת ורצה בפעם הבאה בלי AI (אם כל הצעדים שלה פשוטים).
- "תשכח את הקיצור מצב עבודה"
- "תזכור שאני אוהב קפה בלי סוכר" / "תשכח ש..."

**כל השאר הולך ל-Claude Code במחשב, עם הידיים של HELPER:**
- "מה כתוב פה?", "מה לא בסדר בקוד הזה?" (הוא מצלם את המסך ומסתכל)
- "איפה מדליקים את מצב הלילה?" (מסמן עיגול על המקום)
- "תמצא לי את הקובץ של החשבונית מאתמול"
- "מה כתבו לי בוואטסאפ?", "מה יש לי מחר ביומן?" (שואל את HELPER בענן)

**בטיחות:** לפני כל שליחה, מחיקה, קנייה או שינוי הגדרה מופיע כרטיס "לאשר?". רק Enter או "כן" ממשיכים. ל-Claude מותר להריץ במחשב רק את הידיים של HELPER, ולקרוא ולחפש. הוא לא כותב קבצים ולא מריץ פקודות מערכת.

## התקנה

```powershell
cd desktop
powershell -ExecutionPolicy Bypass -File get-speech.ps1   # מנוע הדיבור: whisper.cpp + המודל העברי של ivrit.ai (2.3GB)
powershell -ExecutionPolicy Bypass -File install.ps1      # קיצור דרך בתפריט התחל ובשולחן העבודה, ומפעיל
```

‏פעם אחת:
1. **Claude Code:** בטרמינל `claude`, ואז `/login` עם החשבון שלך. בלי זה, שאלות שהן לא פקודות מיידיות עונה HELPER מהענן.
2. **HELPER בענן:** `powershell -ExecutionPolicy Bypass -File connect.ps1`, ומקלידים את קוד החיבור (bridge token). הקוד נשמר רק במחשב.

**דרישות:** Windows 10/11, Node 20+, וכרטיס מסך NVIDIA לדיבור מהיר (בלי כרטיס כזה, להוריד מ-whisper.cpp את הגרסה ל-CPU).

## איך זה בנוי

| קובץ | מה |
|---|---|
| `main.js` | האפליקציה: מקשים (uiohook), הבועה, ההכתבה, ההצבעה, צילום מסך, ניתוב השאלות |
| `src/instant.js` | הפקודות המיידיות בעברית: משפט לצעדים |
| `src/hands.js` | הידיים: כל פעולה במחשב, צעד `{cmd, args}` שאפשר לשמור ולהריץ שוב |
| `src/win32.js` | קריאות ישירות ל-Windows דרך koffi: חלונות, מיקוד, מקשים, הקלדה, עכבר |
| `src/apps.js` | האפליקציות מתפריט התחל, עם שמות בעברית |
| `src/speech.js` | דיבור לטקסט על כרטיס המסך (whisper.cpp + ivrit.ai) |
| `src/brain.js` | Claude Code (`claude.exe -p`) עם הידיים, ו-HELPER בענן (`/bridge/ask`) |
| `src/hands-server.js` + `bin/hands.mjs` | הידיים בשביל Claude Code, בפורט מקומי עם מפתח |
| `src/store.js` | הגדרות, זיכרון, קיצורים ולוג ב-`%APPDATA%\helper-desktop` |
| `ui/` | הבועה, ההכתבה, שכבת ההצבעה (בלי סקריפטים בתוך הדפים) |

## בדיקות

```powershell
npm run check                  # 64 בדיקות של הפקודות בעברית ושל ניקוי הדיבור, בלי המחשב
node test/apps-check.js        # איזו אפליקציה כל שם מוצא, במחשב הזה
node test/speech-check.js      # דיבור אמיתי: עובר את בדיקת השקט ומתומלל נכון (צריך ffmpeg)
# עם HELPER רץ:
node test/hotkey-check.js      # מקשים, תיבת הקלדה, החזקה לדיבור, הכתבה
node test/voice-check.js       # מסלול הדיבור המלא: הקלטה ← תמלול ← פקודה ← פנקס רשימות נפתח ← הכתבה לתוכו
node test/point-check.js       # הצבעה במסך
node test/confirm-check.js     # כרטיס "לאשר?", והמקלדת חוזרת לחלון הקודם
```

‏הבדיקות עם HELPER רץ לוחצות רק על החלונות של HELPER ושל פנקס רשימות, ובודקות לפני כל לחיצה שהם אכן בחזית.

`node_moduleselectrondistelectron.exe . --ask "תפתח את ספוטיפיי"` (מתוך desktop) שולח שאלה מבחוץ, כמו הקלדה. זה שימושי לכפתורים ב-Stream Deck.
