# ⚡ HELPER למחשב (Windows) - גרסת 1000x

‏HELPER על המחשב: העוזר האישי החכם והמהיר בעולם ל-Windows 11. מחזיקים מקש ומדברים בעברית (דרך **Voicemod** או כל מיקרופון), והוא שולט במחשב, מסדר חלונות, מנגן ביוטיוב, מנהל כרטיסיות, קורא את לוח ההעתקות, מנתח את המסך בעיניים חכמות (Vision), ומשיב בקול אנושי חי ונעים של **ElevenLabs**.

---

## ⌨️ המקשים

| פעולה | קיצור מקלדת | פירוט |
|---|---|---|
| **לדבר ל-HELPER** | כפתור **PageDown (PD)** או **Ctrl+Alt+Q** (או **F8**) | **Push-to-Talk** (להחזיק ולשחרר) או **Toggle** (לחיצה להתחלה, לחיצה לסיום) |
| **להקליד שאלה** | **לחיצה קצרה** על PD / Ctrl+Alt+Q | פותח תיבת כתיבה מהירה, Enter לשליחה |
| **הכתבה לכל שדה (Dictation)** | להחזיק **Ctrl ימני** | מדברים ומשחררים; הטקסט נכתב ישירות בשדה הפעיל |
| **להצביע על אזור במסך** | **Ctrl+Alt+P** | סימון אזור או לחיצה על כפתור במסך לשאלה חזותית |
| **ביטול / סגירה** | **Esc** | סוגר את הבועה או מבטל פעולה מיד |

## 🚀 כוחות העל של HELPER

### 1. פקודות מיידיות (0ms - 2ms ללא המתנה ל-AI):
- **סביבות עבודה ומסכים:**
  - *"מצב עבודה"* / *"מצב תכנות"* — מסדר מיד קוד (VS Code/Cursor) בצד שמאל ודפדפן בצד ימין.
  - *"מצב קריאה"* — ממקם את הדפדפן במרכז המסך בצורה נוחה.
  - *"נקה מסך"* / *"שולחן עבודה"* — ממזער את כל החלונות.
- **שליטה בדפדפן וכרטיסיות:**
  - *"כרטיסייה חדשה"* (`Ctrl+T`), *"סגור כרטיסייה"* (`Ctrl+W`), *"תחזיר את הטאב"* (`Ctrl+Shift+T`), *"כרטיסייה הבאה"* (`Ctrl+Tab`), *"רענן דף"*.
- **לוח העתקות וקבצים:**
  - *"מה העתקתי?"* — מציג ומקריא את תוכן ה-Clipboard.
  - *"נקה את הלוח"* — מרוקן את לוח ההעתקות.
  - *"מה הקובץ האחרון שהורדתי?"* / *"תפתח את ההורדה האחרונה"*.
  - *"תפתח את ההורדות"* / *"תפתח את המסמכים"* / *"סייר הקבצים"*.
- **מולטימדיה ועוצמת שמע:**
  - *"תפעיל ביוטיוב לופי"*, *"תנגן אופק אדנק נתתי לך בית"*.
  - *"השיר הבא"*, *"הקודם"*, *"עצור"*, *"תמשיך"*.
  - *"ווליום 30"*, *"תגביר"*, *"תנמיך"*, *"השתק"*.
- **חומרה ומערכת:**
  - *"מצב המחשב"* / *"כמה זיכרון פנוי?"* / *"ביצועים"* — מעבד, RAM בשימוש ופנוי, וזמן דליקה.
  - *"מה השעה"*, *"תנעל את המחשב"*.

### 2. מוח כפול חסין נפילות (Dual AI Brain):
- **ראייה ממוחשבת (Vision):** *"מה כתוב פה?"*, *"מה השגיאה הזאת בקוד?"*, *"איפה לוחצים כדי לעשות X?"* — העוזר מנתח את צילום המסך בזמן אמת ומסמן עיגול על המסך היכן ללחוץ.
- **אוטומציה מלאה וכלים:** פתיחת כל אפליקציה מותקנת, הרצת פקודות שורת פקודה בטוחות, מענה על שאלות כלליות, ניסוח מיילים ותרגומים.
- **קול ElevenLabs ישיר עם מטמון מקומי:** קול חי, טבעי ואנושי (Amit) עם השמעה מיידית של 1ms לפקודות שכיחות.
